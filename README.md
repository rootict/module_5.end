# Module 05.4 - Prompt Libraries, Verification & Data Safety

An interactive, web-based presentation designed for the **Foundation Diploma in Digital Technology, AI & Future Skills**. This module covers modern professional workflows, emphasizing efficiency through prompt libraries, critical thinking through output verification, and strict data security protocols.

## 🎯 Learning Objectives
This presentation introduces essential best practices for working with AI in a professional workplace environment:
* **Prompt Libraries:** Saving and reusing proven master templates to scale productivity instead of rewriting from scratch.
* **Output Verification:** Understanding AI hallucinations (probabilistic text vs. factual knowledge) and the necessity of independent fact-checking.
* **Safe Data Handling:** Protecting Personally Identifiable Information (PII), passwords, and corporate secrets using privacy firewalls and anonymization (redaction).
* **The Final Workflow:** A summary recap of the three daily pillars: **Save, Verify, and Protect**.

## ✨ Features
* **Interactive Workspace Simulation:** A click-through prompt library interface displaying real-world templates.
* **Verification Scanner:** A live visual breakdown demonstrating how to catch and correct AI factual errors (hallucinations).
* **Privacy Firewall Animation:** A network packet simulation showing how sensitive data is intercepted and anonymized.
* **Zero Dependencies:** Built entirely with pure HTML, CSS, and vanilla JavaScript.
* **Fully Responsive:** Adapts smoothly across different screen sizes and classroom projectors.
